# Sonnet

Android-клієнт для [Jellyfin](https://jellyfin.org/) у чорно-фіолетових тонах, створений для Galaxy Z Fold.
Ти користуєшся веб-інтерфейсом Jellyfin (Головна, Топ-10, Продовжити перегляд…), а щойно натискаєш «Відтворити»,
керування перебирає **нативний плеєр** (ExoPlayer). У застосунку є й розділ для Bridge Hub.

Sonnet — особистий проєкт, не пов'язаний із проєктом Jellyfin.

## Завантажити APK

➡️ **[Завантажити Sonnet v0.4 (`sonnet.apk`)](https://github.com/apk-fold/sonnet/raw/main/sonnet.apk)**, 22 МБ. Файл також видно
в списку файлів репозиторію.

Контрольна сума SHA-256 для перевірки файлу: `3a39339de771e0e0ab1326ded792f8eab62249b5476c74f9073505ba82328a3d`

Установлення на Android 8.0 або новіший:
1. Завантаж `sonnet.apk` просто на телефон.
2. Відкрий файл. Android попросить дозволити встановлення з цього джерела (браузер або файловий менеджер): погодься.
3. Натисни **Установити**.

Примітки:
- Це **debug**-версія APK (підписана налагоджувальним ключем Android Studio, ідентифікатор `com.matheo.sonnet.debug`).
- **Жодна адреса не зашита в код**: під час першого запуску Sonnet запитає адресу твого сервера Jellyfin (і, за бажанням,
  адресу Bridge Hub). Пізніше їх можна змінити в Налаштуваннях.
- Застосунок дозволяє незашифрований HTTP, що зручно в приватній мережі (Tailscale, локальна мережа).

## Можливості

### Нативний плеєр
- **Положення зображення**: згори, по центру або знизу (кнопка в правому верхньому куті або свайп двома пальцями). На розкладеному Fold можна
  притиснути фільм догори, щоб чорні смуги пішли вниз. Положення запам'ятовується окремо для зовнішнього екрана й
  розкладеного екрана.
- **±10 секунд будь-де**: кнопки ⟲10 і 10⟳ та подвійний дотик ліворуч або праворуч від відео. Кожен наступний дотик додає 10 с.
  Подвійний дотик по центру — пауза. Крок налаштовується (5, 10, 15 або 30 с).
- **Субтитри в чорній смузі**: вони більше не закривають зображення, якщо знизу є місце.
- **Жести**: яскравість (ліворуч), гучність (праворуч), горизонтальний свайп для перемотування з превʼю trickplay,
  щипок для масштабування, довге натискання для швидкості 2×, блокування екрана.
- **Режим «стіл» / «книжка»** (Fold наполовину складений): відео згори, пульт знизу.
- **Автоматична «картинка в картинці»**, відтворення не переривається під час складання й розкладання, MediaSession (Bluetooth, PiP).
- **Пропуск заставки або титрів** (сегменти Jellyfin 10.10+ або розділи), кнопкою або автоматично.
- **Наступна серія** зі зворотним відліком, список серій сезону, розділи з картинками.
- Звукові доріжки й субтитри, швидкість від 0,5 до 3×, таймер сну, максимальна якість і бітрейт, підсилення гучності, відомості
  про відтворення (кодек, пряме відтворення чи перекодування); якщо файл не відтворюється — автоматичний перехід на перекодування, потім у режим сумісності (H.264 + AAC), а екран помилки детально пояснює причину.
- Прогрес синхронізується з Jellyfin (продовження, «Переглянуто», Продовжити перегляд).

### Опції Sonnet (Налаштування › Опції Sonnet)
Кожну опцію можна ввімкнути або вимкнути окремо для Jellyfin і для Bridge Hub:
- **Анімації GSAP**: постери з'являються каскадом, переходи між сторінками, пружний ефект під час дотику, легка вібрація.
- **Шалені ефекти**: анімоване полярне сяйво, 3D-картки, що стежать за пальцем, іскри, заголовки по літерах, паралакс, хвилі від дотику.
- **Потягнути вниз** угорі сторінки: ярлики (Головна, Пошук, Обране, Оновити, Догори).
- **Подвійний дотик до постера** на сторінці опису: в обране. **Свайп по серії**: праворуч — переглянуто / не переглянуто, ліворуч — в обране.
- **Теми**: темна, AMOLED (чисто чорна) і світла, плюс **будь-який акцентний колір**.
- [GSAP](https://gsap.com) (GreenSock) вбудовано в застосунок локально.

### Застосунок
- **Постійний** WebView Jellyfin: вкладки перемикаються миттєво, складання й розкладання нічого не перезавантажують.
- **Бічна панель навігації** ліворуч на розкладеному екрані, нижня панель на зовнішньому екрані.
- **Нативні медіатеки** (з Пошуком, Обраним, ТБ у прямому ефірі) і вкладка Фото.
- **Усі налаштування Jellyfin** у Налаштуваннях: профіль, відображення, головна, відтворення, субтитри, керування, Quick Connect і
  все адміністрування (користувачі, медіатеки, перекодування, плагіни, завдання, журнали, мережа, ТБ, API-ключі,
  резервні копії…). Маршрути перевірено на jellyfin-web 10.11.
- **Фіолетовий акцент, вбудований у Jellyfin** (у налаштуваннях і адмініструванні або всюди), з можливістю власного CSS.
- Повноекранний режим веб-плеєра, надсилання файлів (зображення, субтитри) і «Завантажити» працюють.
- Кнопка «Назад» в Android повертає назад усередині Jellyfin.

Нативний плеєр можна вимкнути в Налаштування › Плеєр Sonnet. У разі помилки відтворення доступний варіант «Відтворити у веб-плеєрі
Jellyfin».

## Зібрати самостійно

Вимоги: Android Studio (або Android SDK) і JDK 17 або новіший.

1. Відкрий теку проєкту (ту, де є `app/`) в Android Studio й дочекайся завершення синхронізації Gradle.
2. Запусти **Build › Build APK(s)** або з командного рядка:
   ```
   gradlew.bat assembleDebug
   ```
3. APK лежить у `app/build/outputs/apk/debug/` або, залежно від версії Android Studio, у
   `app/build/intermediates/apk/debug/`.

Якщо Gradle не може зібрати проєкт, спершу перевір, що в `local.properties` вказано шлях до твого Android SDK
(`sdk.dir=...`) і що `JAVA_HOME` указує на JDK, сумісний із твоєю версією Gradle.

## Технічні деталі

Kotlin і Jetpack Compose, Media3 (ExoPlayer) для відтворення, `androidx.window` для поз Fold, Coil для
постерів, DataStore для налаштувань. Мінімум Android 8.0 (API 26), цільовий API 34.

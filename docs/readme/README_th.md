# Sonnet

ไคลเอนต์ Android สำหรับ [Jellyfin](https://jellyfin.org/) โทนสีดำและม่วง ออกแบบมาสำหรับ Galaxy Z Fold
คุณใช้อินเทอร์เฟซเว็บของ Jellyfin ได้ตามเดิม (หน้าหลัก, Top 10, ดูต่อ…) และทันทีที่กดเล่น
**เครื่องเล่นเนทีฟ** (ExoPlayer) จะรับช่วงต่อ แอปยังมีพื้นที่สำหรับ Bridge Hub ด้วย

Sonnet เป็นโปรเจกต์ส่วนตัว ไม่ได้เกี่ยวข้องกับโปรเจกต์ Jellyfin

## ดาวน์โหลด APK

➡️ **[ดาวน์โหลด Sonnet v0.4 (`sonnet.apk`)](https://github.com/apk-fold/sonnet/raw/main/sonnet.apk)** ขนาด 22 MB ไฟล์นี้ยังเห็นได้
ในรายการไฟล์ของรีโพซิทอรี

ค่าแฮช SHA-256 สำหรับตรวจสอบไฟล์: `3a39339de771e0e0ab1326ded792f8eab62249b5476c74f9073505ba82328a3d`

การติดตั้งบน Android 8.0 ขึ้นไป:
1. ดาวน์โหลด `sonnet.apk` ลงโทรศัพท์โดยตรง
2. เปิดไฟล์ Android จะขอให้อนุญาตการติดตั้งจากแหล่งนี้ (เบราว์เซอร์หรือตัวจัดการไฟล์): กดยอมรับ
3. แตะ **ติดตั้ง**

หมายเหตุ:
- นี่คือ APK แบบ **debug** (ลงนามด้วยคีย์ debug ของ Android Studio, รหัสแอป `com.matheo.sonnet.debug`)
- **ไม่มีที่อยู่ใดถูกฝังไว้ในโค้ด**: เมื่อเปิดครั้งแรก Sonnet จะถามที่อยู่เซิร์ฟเวอร์ Jellyfin ของคุณ (และหากต้องการ
  ที่อยู่ Bridge Hub) เปลี่ยนภายหลังได้ในการตั้งค่า
- แอปอนุญาต HTTP ที่ไม่เข้ารหัส ซึ่งสะดวกเมื่อใช้ในเครือข่ายส่วนตัว (Tailscale, เครือข่ายภายใน)

## ฟีเจอร์

### เครื่องเล่นเนทีฟ
- **ตำแหน่งภาพ**: บน กลาง หรือล่าง (ปุ่มมุมขวาบน หรือปัดสองนิ้ว) บน Fold ที่กางออก คุณสามารถ
  ชิดภาพยนตร์ไว้ด้านบนเพื่อให้แถบดำไปอยู่ด้านล่าง ระบบจำตำแหน่งแยกกันสำหรับหน้าจอด้านนอกและ
  หน้าจอที่กางออก
- **±10 วินาทีได้ทุกที่**: ปุ่ม ⟲10 และ 10⟳ และแตะสองครั้งทางซ้ายหรือขวาของวิดีโอ แตะเพิ่มแต่ละครั้งจะเพิ่มอีก 10 วินาที
  แตะสองครั้งตรงกลาง = หยุดชั่วคราว ปรับระยะได้ (5, 10, 15 หรือ 30 วินาที)
- **คำบรรยายในแถบดำ**: คำบรรยายจะไม่บังภาพอีกต่อไปเมื่อด้านล่างมีพื้นที่
- **ท่าทาง**: ความสว่าง (ด้านซ้าย), ระดับเสียง (ด้านขวา), ปัดแนวนอนเพื่อเลื่อนพร้อมภาพตัวอย่าง trickplay,
  บีบเพื่อซูม, กดค้างเพื่อเล่นความเร็ว 2×, ล็อกหน้าจอ
- **โหมดตั้งโต๊ะ / หนังสือ** (Fold พับครึ่ง): วิดีโออยู่ด้านบน รีโมตอยู่ด้านล่าง
- **ภาพซ้อนภาพอัตโนมัติ**, เล่นต่อได้แม้พับหรือกางเครื่อง, MediaSession (Bluetooth, PiP)
- **ข้ามช่วงเปิดหรือช่วงเครดิต** (เซกเมนต์ของ Jellyfin 10.10+ หรือบท) แบบปุ่มหรืออัตโนมัติ
- **ตอนถัดไป** พร้อมนับถอยหลัง, รายการตอนของซีซัน, บทพร้อมภาพ
- แทร็กเสียงและคำบรรยาย, ความเร็ว 0.5 ถึง 3×, ตั้งเวลาปิด, คุณภาพและบิตเรตสูงสุด, เพิ่มระดับเสียง, ข้อมูล
  การเล่น (โคเดก, เล่นโดยตรงหรือแปลงรหัส); หากไฟล์เล่นไม่ได้ จะสลับไปแปลงรหัสโดยอัตโนมัติ แล้วจึงไปโหมดเข้ากันได้ (H.264 + AAC) และหน้าจอข้อผิดพลาดจะอธิบายสาเหตุ
- ความคืบหน้าซิงค์กับ Jellyfin (เล่นต่อ, "ดูแล้ว", ดูต่อ)

### ตัวเลือกของ Sonnet (การตั้งค่า › ตัวเลือกของ Sonnet)
แต่ละตัวเลือกเปิดหรือปิดแยกกันได้ ทั้งสำหรับ Jellyfin และ Bridge Hub:
- **แอนิเมชัน GSAP**: โปสเตอร์ปรากฏไล่ลำดับ, การเปลี่ยนหน้า, เอฟเฟกต์สปริงเมื่อแตะ, การสั่นเบา ๆ
- **เอฟเฟกต์สุดเหวี่ยง**: แสงออโรราเคลื่อนไหว, การ์ด 3D ที่เอียงตามนิ้ว, ประกายไฟ, ชื่อเรื่องที่ปรากฏทีละตัวอักษร, พารัลแลกซ์, ระลอกคลื่นเมื่อแตะ
- **ดึงลง** ที่ด้านบนของหน้า: ทางลัด (หน้าหลัก, ค้นหา, รายการโปรด, รีเฟรช, กลับขึ้นบนสุด)
- **แตะสองครั้งที่โปสเตอร์** ในหน้ารายละเอียด: รายการโปรด **ปัดตอน**: ไปทางขวา = ดูแล้ว / ยังไม่ดู, ไปทางซ้าย = รายการโปรด
- **ธีม** มืด, AMOLED (ดำสนิท) และสว่าง พร้อม **สีเน้นที่เลือกเองได้**
- [GSAP](https://gsap.com) (GreenSock) ถูกฝังไว้ในแอปแบบออฟไลน์

### แอป
- WebView ของ Jellyfin แบบ **คงอยู่ตลอด**: สลับแท็บได้ทันที พับหรือกางเครื่องไม่ต้องโหลดใหม่
- **แถบนำทาง** ด้านซ้ายบนหน้าจอที่กางออก และแถบด้านล่างบนหน้าจอด้านนอก
- **คลังสื่อแบบเนทีฟ** (พร้อมค้นหา, รายการโปรด, ทีวีสด) และแท็บรูปภาพ
- **การตั้งค่าทั้งหมดของ Jellyfin** ในการตั้งค่า: โปรไฟล์, การแสดงผล, หน้าหลัก, การเล่น, คำบรรยาย, การควบคุม, Quick Connect และ
  การดูแลระบบทั้งหมด (ผู้ใช้, คลังสื่อ, การแปลงรหัส, ปลั๊กอิน, งาน, บันทึก, เครือข่าย, ทีวี, คีย์ API,
  การสำรองข้อมูล…) เส้นทางทั้งหมดตรวจสอบแล้วบน jellyfin-web 10.11
- **สีเน้นม่วงที่แทรกเข้าไปใน Jellyfin** (เฉพาะการตั้งค่าและการดูแลระบบ หรือทุกที่) พร้อมใส่ CSS ของตัวเองได้
- โหมดเต็มจอของเครื่องเล่นเว็บ, การอัปโหลดไฟล์ (รูปภาพ, คำบรรยาย) และ "ดาวน์โหลด" ใช้งานได้
- ปุ่มย้อนกลับของ Android จะย้อนกลับภายใน Jellyfin

ปิดเครื่องเล่นเนทีฟได้ใน การตั้งค่า › เครื่องเล่น Sonnet หากเล่นผิดพลาด มีตัวเลือก "เล่นด้วยเครื่องเล่นเว็บของ
Jellyfin"

## คอมไพล์เอง

สิ่งที่ต้องมี: Android Studio (หรือ Android SDK) และ JDK 17 ขึ้นไป

1. เปิดโฟลเดอร์โปรเจกต์ (โฟลเดอร์ที่มี `app/`) ใน Android Studio แล้วรอให้ Gradle ซิงค์เสร็จ
2. สั่ง **Build › Build APK(s)** หรือใช้บรรทัดคำสั่ง:
   ```
   gradlew.bat assembleDebug
   ```
3. APK จะอยู่ใน `app/build/outputs/apk/debug/` หรือ ขึ้นอยู่กับเวอร์ชันของ Android Studio อยู่ใน
   `app/build/intermediates/apk/debug/`

หาก Gradle คอมไพล์ไม่ผ่าน ให้ตรวจสอบก่อนว่า `local.properties` มีพาธของ Android SDK
(`sdk.dir=...`) และ `JAVA_HOME` ชี้ไปยัง JDK ที่เข้ากันได้กับเวอร์ชัน Gradle ของคุณ

## รายละเอียดทางเทคนิค

Kotlin และ Jetpack Compose, Media3 (ExoPlayer) สำหรับการเล่น, `androidx.window` สำหรับท่าทางของ Fold, Coil สำหรับ
โปสเตอร์, DataStore สำหรับการตั้งค่า ขั้นต่ำ Android 8.0 (API 26) เป้าหมาย API 34

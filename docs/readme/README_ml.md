# Sonnet

[Jellyfin](https://jellyfin.org/)-നുള്ള Android ക്ലയന്റ്, കറുപ്പും വയലറ്റും നിറങ്ങളിൽ, Galaxy Z Fold-നായി രൂപകൽപ്പന ചെയ്തത്.
Jellyfin വെബ് ഇന്റർഫേസ് (ഹോം, ടോപ്പ് 10, കാണൽ തുടരുക…) അതേപടി ഉപയോഗിക്കാം; പ്ലേ അമർത്തിയാലുടൻ
ഒരു **നേറ്റീവ് പ്ലേയർ** (ExoPlayer) ചുമതലയേൽക്കുന്നു. ആപ്പിൽ ഒരു Bridge Hub-നുള്ള ഇടവുമുണ്ട്.

Sonnet ഒരു വ്യക്തിഗത പ്രോജക്റ്റാണ്, Jellyfin പ്രോജക്റ്റുമായി ബന്ധമില്ല.

## APK ഡൗൺലോഡ് ചെയ്യുക

➡️ **[Sonnet v0.4 ഡൗൺലോഡ് ചെയ്യുക (`sonnet.apk`)](https://github.com/apk-fold/sonnet/raw/main/sonnet.apk)**, 22 MB. ഫയൽ
റിപ്പോസിറ്ററിയുടെ ഫയൽ ലിസ്റ്റിലും കാണാം.

ഫയൽ പരിശോധിക്കാനുള്ള SHA-256 ഹാഷ്: `3a39339de771e0e0ab1326ded792f8eab62249b5476c74f9073505ba82328a3d`

Android 8.0 അല്ലെങ്കിൽ പുതിയതിൽ ഇൻസ്റ്റാൾ ചെയ്യൽ:
1. `sonnet.apk` നേരിട്ട് ഫോണിലേക്ക് ഡൗൺലോഡ് ചെയ്യുക.
2. ഫയൽ തുറക്കുക. ഈ ഉറവിടത്തിൽ (ബ്രൗസർ അല്ലെങ്കിൽ ഫയൽ മാനേജർ) നിന്ന് ഇൻസ്റ്റാൾ ചെയ്യാൻ Android അനുമതി ചോദിക്കും: അംഗീകരിക്കുക.
3. **ഇൻസ്റ്റാൾ ചെയ്യുക** ടാപ്പ് ചെയ്യുക.

കുറിപ്പുകൾ:
- ഇത് ഒരു **debug** APK ആണ് (Android Studio-യുടെ ഡീബഗ് കീ ഉപയോഗിച്ച് സൈൻ ചെയ്തത്, ആപ്പ് ID `com.matheo.sonnet.debug`).
- **ഒരു വിലാസവും കോഡിൽ ഉറപ്പിച്ചിട്ടില്ല**: ആദ്യ തവണ തുറക്കുമ്പോൾ Sonnet നിങ്ങളുടെ Jellyfin സെർവർ വിലാസവും (വേണമെങ്കിൽ
  Bridge Hub വിലാസവും) ചോദിക്കും. പിന്നീട് ക്രമീകരണങ്ങളിൽ മാറ്റാം.
- ആപ്പ് എൻക്രിപ്റ്റ് ചെയ്യാത്ത HTTP അനുവദിക്കുന്നു, ഇത് ഒരു സ്വകാര്യ നെറ്റ്‌വർക്കിൽ (Tailscale, ലോക്കൽ നെറ്റ്‌വർക്ക്) സൗകര്യപ്രദമാണ്.

## ഫീച്ചറുകൾ

### നേറ്റീവ് പ്ലേയർ
- **ചിത്രത്തിന്റെ സ്ഥാനം**: മുകളിൽ, മധ്യത്തിൽ, താഴെ (മുകളിൽ വലതുവശത്തെ ബട്ടൺ, അല്ലെങ്കിൽ രണ്ട് വിരൽ സ്വൈപ്പ്). തുറന്ന Fold-ൽ സിനിമ
  മുകളിലേക്ക് ചേർത്തുവെച്ച് കറുത്ത വരകൾ താഴേക്ക് മാറ്റാം. പുറം സ്ക്രീനിനും
  തുറന്ന സ്ക്രീനിനും സ്ഥാനം വെവ്വേറെ ഓർമ്മിക്കുന്നു.
- **എല്ലായിടത്തും ±10 സെക്കൻഡ്**: ⟲10, 10⟳ ബട്ടണുകൾ, വീഡിയോയുടെ ഇടത്തോ വലത്തോ ഇരട്ട ടാപ്പ്. ഓരോ അധിക ടാപ്പും 10 സെ. കൂട്ടുന്നു.
  മധ്യത്തിൽ ഇരട്ട ടാപ്പ് = താൽക്കാലികമായി നിർത്തുക. ചാട്ടം ക്രമീകരിക്കാം (5, 10, 15 അല്ലെങ്കിൽ 30 സെ.).
- **കറുത്ത വരയിൽ സബ്‌ടൈറ്റിലുകൾ**: താഴെ ഇടമുണ്ടെങ്കിൽ സബ്‌ടൈറ്റിലുകൾ ഇനി ചിത്രം മറയ്ക്കില്ല.
- **ജെസ്‌ചറുകൾ**: തെളിച്ചം (ഇടതുവശം), ശബ്ദം (വലതുവശം), trickplay പ്രിവ്യൂവോടെ മുന്നോട്ട്/പിന്നോട്ട് പോകാൻ തിരശ്ചീന സ്വൈപ്പ്,
  സൂമിനായി പിഞ്ച്, 2× വേഗതയ്ക്കായി നീണ്ട അമർത്തൽ, സ്ക്രീൻ ലോക്ക്.
- **ടേബിൾടോപ്പ് / ബുക്ക് മോഡ്** (Fold പാതി മടക്കിയത്): വീഡിയോ മുകളിൽ, റിമോട്ട് താഴെ.
- **ഓട്ടോമാറ്റിക് പിക്ചർ-ഇൻ-പിക്ചർ**, മടക്കുമ്പോഴും തുറക്കുമ്പോഴും തുടരുന്ന പ്ലേബാക്ക്, MediaSession (Bluetooth, PiP).
- **ഇൻട്രോ അല്ലെങ്കിൽ ക്രെഡിറ്റുകൾ ഒഴിവാക്കുക** (Jellyfin 10.10+ സെഗ്‌മെന്റുകൾ അല്ലെങ്കിൽ അധ്യായങ്ങൾ), ബട്ടൺ വഴിയോ സ്വയമേവയോ.
- കൗണ്ട്‌ഡൗണോടെ **അടുത്ത എപ്പിസോഡ്**, സീസണിലെ എപ്പിസോഡുകളുടെ ലിസ്റ്റ്, ചിത്രങ്ങളോടു കൂടിയ അധ്യായങ്ങൾ.
- ഓഡിയോ, സബ്‌ടൈറ്റിൽ ട്രാക്കുകൾ, 0.5 മുതൽ 3× വരെ വേഗത, സ്ലീപ്പ് ടൈമർ, പരമാവധി ഗുണനിലവാരവും ബിറ്റ്‌റേറ്റും, ശബ്ദ ബൂസ്റ്റ്, പ്ലേബാക്ക്
  വിവരങ്ങൾ (കോഡെക്, നേരിട്ടുള്ള പ്ലേ അല്ലെങ്കിൽ ട്രാൻസ്‌കോഡിംഗ്); ഒരു ഫയൽ പ്ലേ ആകുന്നില്ലെങ്കിൽ സ്വയമേവ ട്രാൻസ്‌കോഡിംഗിലേക്കും തുടർന്ന് അനുയോജ്യതാ മോഡിലേക്കും (H.264 + AAC) മാറുന്നു; പിശക് സ്ക്രീൻ കാരണം വിശദീകരിക്കുന്നു.
- Jellyfin-മായി സിങ്ക് ചെയ്യുന്ന പുരോഗതി (തുടരുക, "കണ്ടു", കാണൽ തുടരുക).

### Sonnet ഓപ്ഷനുകൾ (ക്രമീകരണങ്ങൾ › Sonnet ഓപ്ഷനുകൾ)
ഓരോ ഓപ്ഷനും Jellyfin-നും Bridge Hub-നും വെവ്വേറെ ഓൺ/ഓഫ് ചെയ്യാം:
- **GSAP ആനിമേഷനുകൾ**: ഒന്നിനു പുറകെ ഒന്നായി വരുന്ന പോസ്റ്ററുകൾ, പേജ് ട്രാൻസിഷനുകൾ, സ്പർശിക്കുമ്പോൾ സ്പ്രിംഗ് ഇഫക്റ്റ്, ലഘുവായ വൈബ്രേഷനുകൾ.
- **അടിപൊളി ഇഫക്റ്റുകൾ**: ചലിക്കുന്ന ധ്രുവദീപ്തി, വിരൽ പിന്തുടരുന്ന 3D കാർഡുകൾ, തീപ്പൊരികൾ, അക്ഷരം തോറും തെളിയുന്ന തലക്കെട്ടുകൾ, പാരലാക്സ്, സ്പർശന തരംഗങ്ങൾ.
- ഒരു പേജിന്റെ മുകളിൽ **താഴേക്ക് വലിക്കുക**: കുറുക്കുവഴികൾ (ഹോം, തിരയൽ, പ്രിയപ്പെട്ടവ, പുതുക്കുക, പേജിന്റെ മുകളിലേക്ക്).
- വിശദാംശ പേജിൽ **പോസ്റ്ററിൽ ഇരട്ട ടാപ്പ്**: പ്രിയപ്പെട്ടത്. **ഒരു എപ്പിസോഡ് സ്വൈപ്പ് ചെയ്യുക**: വലത്തേക്ക് = കണ്ടു / കണ്ടില്ല, ഇടത്തേക്ക് = പ്രിയപ്പെട്ടത്.
- **തീമുകൾ** ഡാർക്ക്, AMOLED (ശുദ്ധമായ കറുപ്പ്), ലൈറ്റ്, കൂടാതെ **ഇഷ്ടമുള്ള ആക്‌സന്റ് നിറം**.
- [GSAP](https://gsap.com) (GreenSock) ആപ്പിൽ ലോക്കലായി ഉൾപ്പെടുത്തിയിട്ടുണ്ട്.

### ആപ്പ്
- **സ്ഥിരമായ** Jellyfin WebView: ടാബുകൾ മാറ്റുന്നത് തൽക്ഷണം, മടക്കുകയോ തുറക്കുകയോ ചെയ്താൽ ഒന്നും വീണ്ടും ലോഡ് ചെയ്യുന്നില്ല.
- തുറന്ന സ്ക്രീനിൽ ഇടതുവശത്ത് **നാവിഗേഷൻ റെയിൽ**, പുറം സ്ക്രീനിൽ താഴെ ബാർ.
- **നേറ്റീവ് ലൈബ്രറികൾ** (തിരയൽ, പ്രിയപ്പെട്ടവ, ലൈവ് ടിവി എന്നിവയോടെ) കൂടാതെ ഫോട്ടോസ് ടാബ്.
- ക്രമീകരണങ്ങളിൽ **Jellyfin-ന്റെ എല്ലാ ക്രമീകരണങ്ങളും**: പ്രൊഫൈൽ, ഡിസ്‌പ്ലേ, ഹോം, പ്ലേബാക്ക്, സബ്‌ടൈറ്റിലുകൾ, നിയന്ത്രണങ്ങൾ, Quick Connect, കൂടാതെ
  മുഴുവൻ അഡ്മിനിസ്‌ട്രേഷനും (ഉപയോക്താക്കൾ, ലൈബ്രറികൾ, ട്രാൻസ്‌കോഡിംഗ്, പ്ലഗിനുകൾ, ടാസ്‌ക്കുകൾ, ലോഗുകൾ, നെറ്റ്‌വർക്ക്, ടിവി, API കീകൾ,
  ബാക്കപ്പുകൾ…). റൂട്ടുകൾ jellyfin-web 10.11-ൽ പരിശോധിച്ചിട്ടുണ്ട്.
- **Jellyfin-ൽ ചേർത്ത വയലറ്റ് ആക്‌സന്റ്** (ക്രമീകരണങ്ങളിലും അഡ്മിനിസ്‌ട്രേഷനിലും, അല്ലെങ്കിൽ എല്ലായിടത്തും), ഇഷ്ടാനുസൃത CSS സാധ്യതയോടെ.
- വെബ് പ്ലേയറിന്റെ ഫുൾ സ്ക്രീൻ, ഫയൽ അപ്‌ലോഡ് (ചിത്രങ്ങൾ, സബ്‌ടൈറ്റിലുകൾ), "ഡൗൺലോഡ്" എന്നിവ പ്രവർത്തിക്കുന്നു.
- Android-ന്റെ ബാക്ക് ബട്ടൺ Jellyfin-നുള്ളിൽ പിന്നോട്ട് പോകുന്നു.

നേറ്റീവ് പ്ലേയർ ക്രമീകരണങ്ങൾ › Sonnet പ്ലേയർ എന്നതിൽ ഓഫ് ചെയ്യാം. പ്ലേബാക്ക് പിശക് ഉണ്ടായാൽ "Jellyfin വെബ്
പ്ലേയർ ഉപയോഗിച്ച് പ്ലേ ചെയ്യുക" ലഭ്യമാണ്.

## സ്വയം ബിൽഡ് ചെയ്യാൻ

ആവശ്യമുള്ളവ: Android Studio (അല്ലെങ്കിൽ Android SDK), JDK 17 അല്ലെങ്കിൽ പുതിയത്.

1. പ്രോജക്റ്റ് ഫോൾഡർ (`app/` ഉള്ളത്) Android Studio-യിൽ തുറന്ന് Gradle സിങ്ക് പൂർത്തിയാകാൻ അനുവദിക്കുക.
2. **Build › Build APK(s)** പ്രവർത്തിപ്പിക്കുക, അല്ലെങ്കിൽ കമാൻഡ് ലൈനിൽ:
   ```
   gradlew.bat assembleDebug
   ```
3. APK `app/build/outputs/apk/debug/`-ൽ ആണ്, അല്ലെങ്കിൽ Android Studio പതിപ്പ് അനുസരിച്ച്
   `app/build/intermediates/apk/debug/`-ൽ.

Gradle-ന് ബിൽഡ് ചെയ്യാൻ കഴിയുന്നില്ലെങ്കിൽ, ആദ്യം `local.properties`-ൽ നിങ്ങളുടെ Android SDK-യുടെ പാത
(`sdk.dir=...`) ഉണ്ടോ എന്നും `JAVA_HOME` നിങ്ങളുടെ Gradle പതിപ്പിന് അനുയോജ്യമായ JDK-യിലേക്ക് ചൂണ്ടുന്നുണ്ടോ എന്നും പരിശോധിക്കുക.

## സാങ്കേതിക വിവരങ്ങൾ

Kotlin, Jetpack Compose, പ്ലേബാക്കിന് Media3 (ExoPlayer), Fold പോസ്‌ചറുകൾക്ക് `androidx.window`, പോസ്റ്ററുകൾക്ക് Coil,
ക്രമീകരണങ്ങൾക്ക് DataStore. കുറഞ്ഞത് Android 8.0 (API 26), ടാർഗെറ്റ് API 34.

## v0.5 – Jellyfin Android-ൽ നിന്ന് പ്രചോദനം ഉൾക്കൊണ്ട പ്ലേയർ
വീണ്ടും എഴുതിയ ഉപകരണ പ്രൊഫൈൽ (ഫോണിന്റെ യഥാർത്ഥ ഡീകോഡറുകൾ), Jellyfin പ്രോജക്റ്റ് നൽകുന്ന FFmpeg ഓഡിയോ ഡീകോഡറുകൾ (AC3, E-AC3, DTS, TrueHD…), ശരിയാക്കിയ പ്ലേബാക്ക് URL-കൾ (direct play / direct stream / ട്രാൻസ്‌കോഡിംഗ്), വലിയ നെറ്റ്‌വർക്ക് ബഫറുകൾ. GitHub Actions വഴി സ്വയമേവയുള്ള ബിൽഡ്.

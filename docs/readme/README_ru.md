# Sonnet

Android-клиент для [Jellyfin](https://jellyfin.org/) в чёрно-фиолетовых тонах, созданный для Galaxy Z Fold.
Ты пользуешься веб-интерфейсом Jellyfin (Главная, Топ-10, Продолжить просмотр…), а как только нажимаешь «Воспроизвести»,
управление берёт **нативный плеер** (ExoPlayer). В приложении есть и раздел для Bridge Hub.

Sonnet — личный проект, не связанный с проектом Jellyfin.

## Скачать APK

➡️ **[Скачать Sonnet v0.4 (`sonnet.apk`)](https://github.com/apk-fold/sonnet/raw/main/sonnet.apk)**, 22 МБ. Файл также виден
в списке файлов репозитория.

Контрольная сумма SHA-256 для проверки файла: `3a39339de771e0e0ab1326ded792f8eab62249b5476c74f9073505ba82328a3d`

Установка на Android 8.0 или новее:
1. Скачай `sonnet.apk` прямо на телефон.
2. Открой файл. Android попросит разрешить установку из этого источника (браузер или файловый менеджер): согласись.
3. Нажми **Установить**.

Примечания:
- Это **debug**-версия APK (подписана отладочным ключом Android Studio, идентификатор `com.matheo.sonnet.debug`).
- **Ни один адрес не зашит в код**: при первом запуске Sonnet спросит адрес твоего сервера Jellyfin (и, по желанию,
  адрес Bridge Hub). Потом их можно изменить в Настройках.
- Приложение разрешает незашифрованный HTTP, что удобно в частной сети (Tailscale, локальная сеть).

## Возможности

### Нативный плеер
- **Положение изображения**: сверху, по центру или снизу (кнопка в правом верхнем углу или свайп двумя пальцами). На разложенном Fold можно
  прижать фильм к верху, чтобы чёрные полосы ушли вниз. Положение запоминается отдельно для внешнего экрана и
  разложенного экрана.
- **±10 секунд где угодно**: кнопки ⟲10 и 10⟳ и двойное касание слева или справа от видео. Каждое следующее касание добавляет 10 с.
  Двойное касание по центру — пауза. Шаг настраивается (5, 10, 15 или 30 с).
- **Субтитры в чёрной полосе**: они больше не закрывают изображение, если снизу есть место.
- **Жесты**: яркость (слева), громкость (справа), горизонтальный свайп для перемотки с превью trickplay,
  щипок для масштабирования, долгое нажатие для скорости 2×, блокировка экрана.
- **Режим «стол» / «книга»** (Fold наполовину сложен): видео сверху, пульт снизу.
- **Автоматическая «картинка в картинке»**, воспроизведение не прерывается при складывании и раскладывании, MediaSession (Bluetooth, PiP).
- **Пропуск заставки или титров** (сегменты Jellyfin 10.10+ или главы), кнопкой или автоматически.
- **Следующая серия** с обратным отсчётом, список серий сезона, главы с картинками.
- Звуковые дорожки и субтитры, скорость от 0,5 до 3×, таймер сна, максимальное качество и битрейт, усиление громкости, сведения
  о воспроизведении (кодек, прямое воспроизведение или перекодирование); если файл не воспроизводится — автоматический переход на перекодирование, затем в режим совместимости (H.264 + AAC), а экран ошибки подробно объясняет причину.
- Прогресс синхронизируется с Jellyfin (продолжение, «Просмотрено», Продолжить просмотр).

### Опции Sonnet (Настройки › Опции Sonnet)
Каждую опцию можно включить или выключить отдельно для Jellyfin и для Bridge Hub:
- **Анимации GSAP**: постеры появляются каскадом, переходы между страницами, пружинящий эффект при касании, лёгкая вибрация.
- **Безумные эффекты**: анимированное полярное сияние, 3D-карточки, следующие за пальцем, искры, заголовки по буквам, параллакс, волны при касании.
- **Потянуть вниз** в верхней части страницы: ярлыки (Главная, Поиск, Избранное, Обновить, Наверх).
- **Двойное касание постера** на странице описания: в избранное. **Свайп по серии**: вправо — просмотрено / не просмотрено, влево — в избранное.
- **Темы**: тёмная, AMOLED (чисто чёрная) и светлая, плюс **любой акцентный цвет**.
- [GSAP](https://gsap.com) (GreenSock) встроен в приложение локально.

### Приложение
- **Постоянный** WebView Jellyfin: вкладки переключаются мгновенно, при складывании и раскладывании ничего не перезагружается.
- **Боковая панель навигации** слева на разложенном экране, нижняя панель на внешнем экране.
- **Нативные медиатеки** (с Поиском, Избранным, ТВ в прямом эфире) и вкладка Фото.
- **Все настройки Jellyfin** в Настройках: профиль, отображение, главная, воспроизведение, субтитры, управление, Quick Connect и
  всё администрирование (пользователи, медиатеки, перекодирование, плагины, задачи, журналы, сеть, ТВ, API-ключи,
  резервные копии…). Маршруты проверены на jellyfin-web 10.11.
- **Фиолетовый акцент, внедрённый в Jellyfin** (в настройках и администрировании или везде), с возможностью своего CSS.
- Полноэкранный режим веб-плеера, отправка файлов (изображения, субтитры) и «Скачать» работают.
- Кнопка «Назад» в Android возвращает назад внутри Jellyfin.

Нативный плеер можно отключить в Настройки › Плеер Sonnet. При ошибке воспроизведения доступен вариант «Воспроизвести в веб-плеере
Jellyfin».

## Собрать самому

Требования: Android Studio (или Android SDK) и JDK 17 или новее.

1. Открой папку проекта (ту, где лежит `app/`) в Android Studio и дождись окончания синхронизации Gradle.
2. Запусти **Build › Build APK(s)** или из командной строки:
   ```
   gradlew.bat assembleDebug
   ```
3. APK находится в `app/build/outputs/apk/debug/` или, в зависимости от версии Android Studio, в
   `app/build/intermediates/apk/debug/`.

Если Gradle не может собрать проект, сначала проверь, что в `local.properties` указан путь к твоему Android SDK
(`sdk.dir=...`) и что `JAVA_HOME` указывает на JDK, совместимый с твоей версией Gradle.

## Технические детали

Kotlin и Jetpack Compose, Media3 (ExoPlayer) для воспроизведения, `androidx.window` для поз Fold, Coil для
постеров, DataStore для настроек. Минимум Android 8.0 (API 26), целевой API 34.
